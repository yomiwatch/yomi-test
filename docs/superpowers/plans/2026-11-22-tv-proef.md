# Tv-proef Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Op de echte Titan OS-tv meten wat de browser kan (codecs, HDR, afspelen van HLS, toetscodes) en of een publieke https-pagina een Yomi-achtige server op het thuisnetwerk mag bereiken, zodat de bouwplannen voor server, app en koppeldienst op feiten rusten.

**Architecture:** Een statische testpagina (`proef/pagina/`) draait alle metingen automatisch en toont de uitkomst groot op het scherm. Een kleine Node-server (`proef/server/`) op de Mac of Unraid-pc in het thuisnetwerk serveert testvideo's, een ping-eindpunt en ontvangt het rapport. De server gebruikt het publieke wildcard-certificaat van `local-ip.sh`, zodat `https://<ip-met-streepjes>.local-ip.sh:8443` een geldig certificaat heeft en naar een privé-IP wijst — precies de situatie van Yomi Connect.

**Tech Stack:** Node 24 (ingebouwde TypeScript-type-stripping en `node:test`, geen npm-runtime-afhankelijkheden voor de server), plain ES-modules in de browser, hls.js 1.5.17 via jsDelivr, ffmpeg 9 (libx264, libx265, aac, ac3, eac3) voor testmedia.

**Spec:** `/Users/jesse/dev/yomi/yomi-server/docs/superpowers/specs/2026-11-21-yomi-design.md` (sectie "Eerste stap: test op de echte tv", "Randvoorwaarden", "3. Koppeldienst").

## Global Constraints

- Alles van de proef staat in `yomi-test/proef/`; het is meetgereedschap, geen productiecode van de app.
- Node-versie: 24 of hoger (`node --test`, `.ts`-bestanden direct uitvoerbaar).
- Server-poorten: https `8443`, http `8080`.
- Hostnaam van de testserver: `<ip met streepjes>.local-ip.sh`, bijv. `192-168-2-6.local-ip.sh`. Certificaat: `https://local-ip.sh/server.pem` en `https://local-ip.sh/server.key` (publiek, alleen voor testen; local-ip.sh biedt sinds 2026 geen certificaat meer).
- De pagina krijgt het serveradres via de query-parameter `?server=192-168-1-20`.
- hls.js exact: `https://cdn.jsdelivr.net/npm/hls.js@1.5.17/dist/hls.min.js`.
- Teksten op de pagina in het Nederlands, minimaal 24px, leesbaar vanaf de bank; alles werkt zonder muis (metingen starten vanzelf).
- Rapporten worden opgeslagen in `proef/resultaten/` en gecommit.
- Elke meting heeft een time-out; één hangende meting mag de rest niet tegenhouden.

## Review Focus

- **Tv kan de LAN-server niet bereiken** (verkeerd IP, firewall, router blokkeert DNS naar privé-IP): de pagina moet codec- en HDR-uitkomsten tóch op het scherm tonen en duidelijk melden "Rapport niet verstuurd", niet blijven hangen. → Task 2 (`netwerk.test.ts`: fetch die faalt) en Task 6 (handmatige controle zonder server).
- **hls.js laadt niet** (CDN geblokkeerd/offline): afspeeltests melden "hls.js niet geladen" en proberen native HLS (`canPlayType('application/vnd.apple.mpegurl')`). → Task 6.
- **Een video die nooit `playing` of `error` geeft**: per stream maximaal 15 s, daarna "time-out" en door naar de volgende. → Task 2 (`metTimeout`).
- **Rapport te groot of geen geldige JSON**: server antwoordt `413` boven 1 MB en `400` bij ongeldige JSON/vorm, en schrijft niets weg. → Task 5.
- **PNA/LNA-preflight**: Chromium kan een `OPTIONS`-preflight met `Access-Control-Request-Private-Network: true` sturen; de server moet die beantwoorden met `Access-Control-Allow-Private-Network: true` én vastleggen dát hij kwam (dat is een meetuitkomst). → Task 5.

### Task 5: Proefserver

**Files:**
- Create: `proef/server/server.ts`, `proef/certs/haal-cert.sh`
- Test: `proef/test/server.test.ts`

**Interfaces:**
- Consumes: `valideerRapport`, `bestandsnaam` (Task 3).
- Produces: `export function maakHandler(opties: { mediaMap: string, paginaMap: string, resultatenMap: string }): (req: IncomingMessage, res: ServerResponse) => void` en een `main()` die bij direct uitvoeren https op `8443` (certs uit `proef/certs/fullchain.pem`, `privkey.pem`) en http op `8080` start met dezelfde handler en de URL's logt.

Gedrag van de handler:
- Elk antwoord: `Access-Control-Allow-Origin: <Origin van het verzoek of *>`, `Vary: Origin`.
- `OPTIONS *`: `204` met `Access-Control-Allow-Methods: GET, POST, OPTIONS`, `Access-Control-Allow-Headers: content-type`, `Access-Control-Max-Age: 0`, en als het verzoek `Access-Control-Request-Private-Network: true` heeft: `Access-Control-Allow-Private-Network: true`. Zet in het geheugen `pnaGezien = true`.
- `GET /ping` → `200` JSON `{ "ok": true, "pnaGezien": <boolean> }`.
- `GET /media/...` → bestanden uit `mediaMap` (`.m3u8` → `application/vnd.apple.mpegurl`, `.mp4` → `video/mp4`, `.m4s` → `video/iso.segment`); pad-traversal (`..`) → `404`.
- `GET /pagina/...` → bestanden uit `paginaMap` (zodat de pagina ook vanaf het LAN te laden is).
- `POST /rapport` → body max 1 048 576 bytes anders `413`; geen JSON of `valideerRapport` geeft `null` → `400`; anders schrijf `{...rapport, pnaGezien}` naar `resultatenMap/bestandsnaam(new Date(), rapport.ua)` en antwoord `201` `{ "opgeslagen": "<bestandsnaam>" }`.

`haal-cert.sh`: download `https://local-ip.sh/fullchain.pem` en `https://local-ip.sh/privkey.pem` naar `proef/certs/`.

### Task 6: Testpagina

**Files:**
- Create: `proef/pagina/index.html`, `proef/pagina/proef.js`, `proef/pagina/ok.txt` (inhoud `ok`)

**Interfaces:**
- Consumes: `CODEC_GEVALLEN`, `meetCodecs`, `meetCapabilities` (Task 1); `metTimeout`, `serverAdressen`, `meetNetwerk` (Task 2); server-eindpunten (Task 5).

Gedrag (`proef.js`, start bij `DOMContentLoaded`, alles automatisch, volgorde vast):
1. **Apparaat:** `navigator.userAgent`, `screen.width×height`, `devicePixelRatio`, `innerWidth×innerHeight`, `matchMedia('(dynamic-range: high)').matches`, `matchMedia('(video-dynamic-range: high)').matches`.
2. **Codecs:** `meetCodecs(MediaSource.isTypeSupported)` (bestaat `MediaSource` niet → alles `false` met melding "Geen MediaSource").
3. **Capabilities:** `meetCapabilities(c => navigator.mediaCapabilities.decodingInfo(c))` (ontbreekt de API → melding).
4. **Netwerk:** `meetNetwerk(serverAdressen(param), fetch)`; zonder geldige `?server=` → sectie toont "Geen server opgegeven (?server=192-168-1-20)".
5. **Afspelen:** voor elk van de vijf varianten uit Task 4, bron `${https}/media/<naam>/index.m3u8`: native HLS als `video.canPlayType('application/vnd.apple.mpegurl')` niet leeg is, anders hls.js (laadt het script niet → uitkomst "hls.js niet geladen"). Geslaagd = `playing` en `currentTime > 2` binnen `metTimeout(…, 15000, naam)`. Vastleggen: `ok`, `videoWidth×videoHeight`, `methode` (`native`/`hls.js`), `fout`. Video's 480×270 in beeld, gedempt, na de meting gestopt en verwijderd.
6. **Rapport:** `POST ${https}/rapport` met `{ versie: 1, ua, tijd: new Date().toISOString(), apparaat, codecs, capabilities, netwerk, afspelen, toetsen }`; uitkomst in beeld: "Rapport opgeslagen als …" of "Rapport niet verstuurd: <fout>".
7. **Toetsen:** sectie die de laatste 12 `keydown`-events toont (`key`, `code`, `keyCode`) met de instructie "Druk op: pijltjes, OK, Terug, Play/Pauze, Rood, Groen, Geel, Blauw, Info".
